# 视频分析 · MVP Beta 使用说明

适用版本：0.1.0-beta.2，Windows x64的Eagle Window插件。固定720p，面向不超过30秒的本地MP4。本版为Beta；核心功能可用，长期内存稳定性和全部素材兼容尚未确认。

## 安装

1. 准备Eagle 4.0 Build 22+并在Eagle中安装FFmpeg模块。本插件不附FFmpeg，用户不需要另装Node.js。
2. 完整解压 `eagle-video-analysis-0.1.0-beta.2-win-x64.zip` 到非C盘可写目录；保留 `native/` 和其他文件，不在ZIP内运行。
3. 在Eagle选择“载入本地插件”，选择包含 `manifest.json` 的整个文件夹。
4. 单选一个不超过30秒的MP4，打开“视频分析 · MVP Beta”。等待自动准备完成，第一帧会暂停待命。

若旧Beta已注册且Eagle提示相同ID，请先关闭并移除旧Beta入口再加载新目录，旧包先保留。开发入口与发行入口ID不同，可以并存，但访问的是同一Eagle素材库；不要同时对同一素材进行写入验收。

## 操作

| 功能 | 方法 |
| --- | --- |
| 播放／暂停 | 点击按钮或按空格；编辑文字时空格正常输入 |
| 拖动定位 | 拖动进度条；上方提示对应已显示帧的时间，松手后暂停 |
| 逐帧 | 上一帧／下一帧按钮，或【／】（英文键盘为 `[`／`]`）；帧数随实际画面变化 |
| 切换视频 | Eagle选中新视频后再次调用插件，或关闭窗口后重开；单纯改变选择不自动换片 |
| 查看标注 | 点击右栏已有标注定位 |
| 添加标注 | 暂停在目标画面，点击“添加”，输入文字后主动“保存” |
| 内存设置 | 展开侧栏，选容量后应用；保留位置，重新准备完成后仍暂停，下次沿用 |
| 清缓存 | 展开“缓存管理”，清除其他视频的完整缓存，保护当前及活跃视频 |

标注保存会修改对应Eagle素材元数据，保存后不会自动删除。修改/删除请用Eagle原生界面；已经打开的原生播放器不保证即时刷新。发布加载验收不要求新建标注。

## 缓存与内存

磁盘缓存位于插件目录的 `cache/`，预算5GiB，包含完整和临时文件。闲置一天的缓存在下次载入时清理；空间不足提前淘汰最久未用项。准备中关闭会取消并清理未完成缓存，完整有效缓存保留供复用；再次打开仍要校验和准备内存，不保证秒开。

RAM默认1GB，可选512MB或1GB～10GB，内部按二进制容量计算，按需占用而非启动即占满。压缩图片最多占其中1/8，与解压图片、音频及在途数据共享总额度。侧栏显示当前视频的受管缓存，不包含浏览器、GPU和FFmpeg全部额外占用，也不是整个插件的内存硬上限。超过本机物理内存的档位拒绝应用；高档位尚未全部实测。

请优先使用内置清理功能。不能确认归属的异常缓存会保留并说明失败，不要手改写锁、清理计划或Eagle素材库。迁移插件时使用干净的新目录，不要求搬运旧缓存或把本机配置写进安装包。

## 已知限制与反馈

H.264、H.265、VP9、4K60及部分不同帧间隔样本已有验证，不能推广到所有机器、参数和素材。仅支持当前短MP4范围，1080p／2K预览、常驻秒刻度、标注修改删除、播放列表和原生播放位置同步不在本版。

约30分钟的旧自动测试曾达到约1.508GiB插件集合内存，超过1.5GiB测试保护线；根因未完全确定。后续短测通过且资源正常释放，但长期稳定性仍待验证。真实Eagle强退、任意磁盘故障和全部高RAM档位也未完整覆盖。

反馈请提供版本、视频时长及已知规格、RAM档位、操作步骤和报错截图，不必上传原视频、整个素材库或私人路径。原始视频不会因生成预览而被修改。

包内 `BUILD-INFO.json` 记录来源提交和逐文件摘要；同页ZIP的SHA256文件用于核对下载内容。静态校验、用户实际加载验收和长期稳定性是不同结论，以本版实际发行记录为准。

项目开源许可证未指定，本包未新增开源许可声明。本包不附Eagle、Node或FFmpeg第三方程序。
