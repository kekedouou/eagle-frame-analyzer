# Eagle Video Analysis · 视频分析

面向 VFX 动效观察的 Eagle Window 视频分析插件。选中 Eagle 中的短视频，即可在独立窗口内播放、快速拖动、逐帧观察，并使用素材已有的时间点文字标注。

当前交付为 **0.1.0-beta.1 内测预览版**，用于展示目前已实现的使用体验，尚未完成 MVP 全部验收。

## 已实现的体验

- **自动准备预览**：打开选中的 MP4 后自动建立 720p 预览缓存，无需切换播放模式。
- **播放与分析结合**：播放／暂停、空格控制、鼠标拖动定位、拖动时显示时间，支持上一帧／下一帧；进度条聚焦时也可使用左右方向键逐帧。
- **复用 Eagle 标注**：显示已有时间点及文字，点击定位；暂停在目标画面后可添加文字标注。
- **可调内存额度**：右栏显示当前视频受管缓存 RAM，折叠设置可按整机物理内存百分比调整，修改后保留位置、重新准备并保持暂停，设置下次沿用。
- **自动管理磁盘缓存**：完整有效缓存保留，未完成的准备在关闭时取消并清理；磁盘预算 5 GiB，按使用情况淘汰非当前缓存。

界面由主画面、底部进度与播放控件、右侧素材／标注栏组成。没有自动测量、实验样本或证据保存按钮。

## 使用条件

- Windows；建议使用最新 Eagle 4，时间点标注接口要求 Eagle 4.0 Build 22 或以上。项目实际测试环境为 Eagle 内 Node 16.17.1／Chrome 108；其他版本未作完整保证。
- Eagle 已安装可供 Plugin API 读取的 FFmpeg 模块（用于生成预览）。本包不附带、不自动安装 FFmpeg，也不要求另外安装 Node.js。缺少模块时插件会提示，按 Eagle 的模块管理功能完成安装后重试。
- 输入为 Eagle 当前**单选**的本地 MP4，时长不超过 30 秒。首版针对 H.264、H.265、VP9；覆盖到 4K／60fps 的输入不代表所有同规格素材均已通过。
- 插件必须解压并放在 **D、E 等非 C 盘的可写普通目录**。完整及临时缓存放插件自身的 `cache` 子目录；不会退回 C 盘或系统临时目录。目录不能通过链接重定向。

## 安装与首次使用

1. 解压内测 ZIP，例如放到 `D:\EaglePlugins\eagle-video-analysis-0.1.0-beta.1-20261014\`。
2. 在 Eagle 的插件开发功能中使用“载入本地插件”，选择**包含 `manifest.json` 的整个解压文件夹**，不要选择 ZIP 或单个文件。
3. 在 Eagle 中单选一个不超过 30 秒的 MP4，打开插件 **“视频分析 · 内测预览”**。
4. 等待右栏准备完成，再播放、拖动或逐帧查看。初次准备可能需要等待；已缓存的视频也需要校验及内存初始化，当前不能保证秒开。
5. 换视频时，关闭插件窗口，在 Eagle 中选中另一视频后再打开。未选视频时可显示空状态；选中后重新调用插件读取当前选择。

这个内测入口具有独立的插件 ID，可以与开发测试入口并存；解压目录的缓存和设置也独立。**两者仍访问同一个 Eagle 素材库**，并不隔离素材标注。

## 标注与内存

添加标注时，点击“添加”，填写文字后点击“保存”；这是用户主动向 Eagle 对应素材写入元数据，保存后的标注不会自动删除。取消未保存输入不会写入。需要删除或修改已保存标注时，使用 Eagle 原生标注界面；本版暂不提供完整标注编辑器。原生播放器已打开时不保证即时刷新，必要时重新打开素材。

RAM 默认额度等效 **1 GiB**，首次启动根据本机物理内存换算百分比；不是启动即占满。压缩图像池最多为该额度的 1/8，图像、音频及处理中的数据共享总预算。该数字不含浏览器、GPU 或 FFmpeg 的额外占用，不能当作整个插件的内存硬上限。内存设置按百分比保存，调低可能使视频无法准备或拖动变慢；初次展示建议保持默认，确认需要后再调整。

## 已知限制与版本状态

- 预览固定 720p；1080p／2K、常驻秒刻度、多视频列表、与原生播放器播放位置同步均不在本次交付中。
- 单段约 26.7 秒的 H.265／4K60 素材，在 1 GiB 缓存额度的真实 Eagle 六轮测试中通过既定拖动指标：三轮快速拖动画布提交约 75～78 次／秒、最长无提交约 83～97ms，随机定位 P95 约 10.5～10.9ms。P95 表示 95% 的被统计操作不超过该延迟。这里测量到画布提交，不是显示器实际呈现时间，不能推广为全部素材的体验保证。
- 同次有效缓存复用就绪约 **39.2 秒**，等待仍需优化；新预算下首次准备、完整样本矩阵及长期资源验收尚未完成。
- 用户已确认开发入口的播放／拖动、标注和内存设置相关体验；**本次独立打包副本尚未进行真实 Eagle 加载验收**。打包检查不能替代宿主验收。
- 本包为阶段 4 的临时展示快照，不是正式稳定版，也不表示 T2／T4 或整个 MVP 已通过。
