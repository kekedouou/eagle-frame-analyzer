# Eagle Video Analysis 0.1.0-beta.1 · 插件内测版

面向VFX短视频观察的Eagle Window插件内测快照。自动准备720p预览，支持正常播放、空格播放／暂停、快速拖动与时间提示、逐帧、Eagle时间点文字标注及RAM百分比设置。没有性能测试按钮。

这是预发行版，不是稳定版，不代表整个MVP或T2/T4验收完成。插件仍是开发主线；本次发行不扩展功能范围。

## 下载与使用

下载附件 `eagle-video-analysis-0.1.0-beta.1-20261014.zip`，不要把GitHub自动提供的Source code ZIP当作已打包插件。

1. 准备Windows、Eagle 4.0 Build 22+及Eagle中的FFmpeg模块。本包不附FFmpeg，无需另装Node.js。
2. 解压到D、E等非C盘的可写普通目录。
3. 在Eagle插件开发功能中“载入本地插件”，选择包含manifest.json的整个解压文件夹。
4. 单选一个不超过30秒的本地MP4，打开“视频分析 · 内测预览”，等待自动准备完成。
5. 换视频时关闭窗口，选中另一素材后再打开。

标注保存会修改对应Eagle素材元数据，保存后不会自动删除；修改/删除请用Eagle原生界面，原生播放器不保证即时刷新。插件副本的缓存和设置独立，Eagle素材标注仍与原素材共享。

## 限制与验证边界

- 预览固定720p，输入针对H.264、H.265、VP9短MP4；不保证所有同规格素材的表现。
- RAM默认等效1GiB，可按本机百分比调整；额度不含浏览器/GPU/FFmpeg额外占用。磁盘缓存预算5GiB。
- 完整缓存复用仍需校验/准备RAM，不承诺秒开；当前尚有明显等待成本。
- 已有正式开发入口的真实Eagle测试及用户体验反馈；打包副本尚未单独完成真实Eagle加载验收。打包核对不替代宿主验收。
- 当前不支持1080p/2K预览、完整标注编辑器、原生播放器播放位置同步。
