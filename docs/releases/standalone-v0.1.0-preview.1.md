## 预备使用说明

计划附件 `video-analysis-standalone-preview-20261014.zip`，约233MiB。GitHub自动Source code ZIP不是可直接运行的绿色软件。

1. 适用Windows 10 22H2或更新的64位Windows。整包解压到非C盘可写目录，不要在ZIP里运行或只复制exe。
2. 双击VideoAnalysisPreview.exe，无需安装Eagle、Node.js或另装FFmpeg。
3. 拖入MP4或视频文件夹，也可用右侧打开按钮；等待当前视频720p缓存准备完成。
4. 通过列表切换视频，只准备当前选中项。支持≤30秒、单文件≤2GiB的普通MP4。

程序data目录在软件同盘，磁盘预算5GiB，RAM默认等效1GiB且可调整；不代表进程总内存硬上限。正常关闭取消/清理未完成缓存，完整有效缓存保留，但再次打开仍有校验/准备等待。关闭并确认进程退出后可删除data清缓存及恢复设置。
