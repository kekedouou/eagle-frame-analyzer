## 实现与入口

正式入口为 `plugin/manifest.json`，HTML/CSS 负责极简主画面与侧栏；不加载原型或测试代码。用户在 Eagle 单选 MP4 后调用插件：自动准备 → 首帧暂停 → 播放/暂停、空格、逐帧及单一拖动时间轴。重新选择视频后，再调用插件入口切换；只改变 Eagle 选择不自动切换。没有旧固定样本或“直接/缓存”切换。

| 文件 | 本轮职责 |
| --- | --- |
| `plugin/app.js` | Eagle 生命周期与模块接线；选择立即捕获，工具发现等待可取消 |
| `plugin/eagle.cjs`、`session.cjs` | Eagle 单选快照、现有工具发现；素材身份、任务串行、取消与旧结果隔离 |
| `plugin/media.cjs`、`cache.cjs` | 真实 PTS 的 JPEG/PCM 准备；非 C 同盘目录、所有权、5GiB 硬预算、排他事务及完整提交 |
| `plugin/player.js`、`frame-index.cjs` | 沿用 T0 验证过的播放/定位核心、512MiB 预算及实际帧索引 |

本轮修复：时间轴获得焦点后空格被误拦截；等待 SDK 工具发现不返回时关闭/切换被阻塞；松手后的实际时间提示及素材库变化提示。按钮/输入框的原有键盘行为、长按保护、拖动中停止声音及旧会话守卫保留。具体测试仍须与真实运行区分。

## 准备耗时排查

正式缓存层逐帧写入重复执行目录、所有权、写锁及提前读回。第一次小范围优化只合并同一无异步等待片段的检查与写入，SHA 使用输入数据作为预期；最终提交仍对真实文件逐一读回核验。音频流与跨异步等待的校验保留，不放宽预算或清理边界。

为保留已有完整缓存，诊断在同一正式受锁/预算保护的事务生成新的 partial，到提交入口完成迁移核对后有意停止，再等待清理。它**不发布新完整缓存，不包含真实提交、租用和界面就绪，不能算完整 P-03**；已有缓存前后目录/文件统计、owner/manifest 哈希及源文件指纹不变，未再次逐个哈希所有保留资产。

保存证据失败会明确拒绝，停止继续写入，不换目录或删除旧记录。可在窗口仍开着时调用 `t.unsavedEvidence()` 取回一份≤2MiB的失败 JSON 字符串；完整当轮轨迹优先保留，实在超限则明确记为无法完整保留，绝不截断后判通过。此内容还在内存中，关闭窗口会丢失，不把它称为已保存证据。

## 用户关闭失败与修复

2026-10-12，用户人工测试反馈：在预缓存中关闭插件后，后续全部视频提示已有占用记录。**记录为真实宿主失败，不是用户误操作；先前本地通过不能覆盖此结果。** 现场确认 `writer.lock` 的 PID 为11676，存在同token的 `partial-3d2b0dee1a36fcb63eb72d55`，含68张JPEG、未完成PCM与owner；9份完整缓存另存，未损坏。

根因：入口只在 `onPluginBeforeExit`/`pagehide` 返回 `session.close()`，但本机Eagle的 `app/js/plugin/main.js` 在BrowserWindow close时仅发送plugin-exit，`app/js/plugin/ipc.js` 同步调用callback且不等待返回Promise，窗口可以先销毁。旧入口模拟主动await回调，只证明会话清理函数可用，漏掉宿主生命周期差异。此前“取消测试通过”不代表实际关窗通过，需修正验证方法。

实现只改入口：以 [Eagle官方关闭拦截方式](https://developer.eagle.cool/plugin-api/zh-cn/api/event#z1a5y) 和 [Electron beforeunload语义](https://www.electronjs.org/docs/latest/api/browser-window#event-close) 同步阻止卸载，调用同一幂等closeTask；等待会话取消、真实子进程与流停止、本事务partial删除及写锁/占用释放后，允许下一次window.close。重复关闭不重复清理；清理拒绝或返回错误时显示失败并保留窗口，不提前放行或删除未知锁。没有修改Eagle安装文件、调用内部窗口IPC或改为后台服务。

新增非等待宿主模型的回归先在旧代码失败：`event.returnValue` 实际为undefined，窗口没有被同步阻止；修复后通过。入口共9组纯/模拟检查，包括重复关闭、清理错误结果与Promise拒绝，以及旧有工具发现取消。模拟窗口不是实际Eagle窗口，修复后的按钮行为仍待用户复验。

现场修复仅针对这次已识别的残留：两次独立进程快照确认PID11676、其子进程及所有ffmpeg/ffprobe均不存在；再核对root实际路径/非C/归属、writer与partial token、固定已知文件名、全部待删文件指纹及稳定状态，先保存预检证据，再逐文件删除该partial和这把写锁，未递归清空根目录。9份完整缓存前后文件名/长度/身份/mtime统计与owner/manifest哈希一致；未对所有保留完整资产重新计算内容哈希，不扩大证明范围。原视频及素材库未写入，不接管其他任务或自动恢复任意陈旧锁。
