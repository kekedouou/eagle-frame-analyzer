## 实现与文件职责

- `plugin/app.js`仍是入口和装配，只读诊断快照补充最多32条本会话保存结果，便于关闭后测试核对。
- `plugin/eagle.cjs`是唯一正式Eagle素材/标注API边界。读当前library.path、按原itemId新取Item并核对路径，复制/排序comments；添加前再次核对库和提案有效性，只调用一次addComment，之后新取Item验证ID/文字/时间。SDK响应丢失后先只读核对，异常或未确认不自动重发，不写metadata.json。
- `plugin/session.cjs`固定库上下文、素材/源指纹、实际帧和源时间。点击添加先暂停并等待实际画面；定位中拒绝添加，输入期间锁定播放/拖动。管理编辑、保存中、成功、明确失败、未知及只读核对；切换不把旧结果应用到其他视频，已发写入完成原身份核对；关窗等待在途核对。
- `plugin/ui.js`、`index.html`、`styles.css`增加极简侧栏列表、时间轴小标记、添加及文字输入。只调session；已有文字以textContent呈现。列表只在读取结果/时长变化时重建，不随每帧重建；空格输入受保护。没有普通刷新、编辑/删除或测试按钮。未知情况下的“核对保存结果”只读原尝试，属于失败恢复，不是标注轮询。
- `tests/support/window-annotations.cjs`是独立宿主观察/具体授权门禁与回退接线；复用`tests/host/window/`及准备脚本的annotations模式，和T2性能/resource模式分开。默认writeApproval为空。该驱动不会自动添加，只允许用户在精确获批提案上点击一次Save；可选的一次删除必须另有allowDelete批准，按原始字段与返回ID核对后执行。
- `tests/support/t2-evidence.cjs`仅复用存储实现，T3独立命名空间/配额。T2原始owner/schema及所有原件保留；资源审计器继续识别历史22源文件集合，新准备集合23份，不把新增T3源伪装成历史长测已测。

用蓝图类比：UI按钮是事件，session先锁定对象与画面，再调用eagle接口函数；成功回调还必须通过另一次读取核对，才显示“已保存”。排错依次看标注区域提示→session提案/状态→eagle读取或保存→宿主观察回执；不先改播放器解码。
