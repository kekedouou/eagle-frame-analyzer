# 产品需求与已批准决定

## 问题与目标

Eagle 原生播放器对部分短 MP4 的拖动响应较慢。希望构建与素材库关联的 VFX 视频分析工具：读取选中素材、独立窗口播放与时间定位、快速拖动预览、手动生成整段缓存，并尽可能复用 Eagle 时间点标注。

主要素材长度 5～30 秒；保留原视频。缓存最终需要内存和磁盘容量控制及画质选择。

## 已批准

- 采用 Eagle Window 插件。它仍属于 Eagle 插件，不是脱离 Eagle 的独立桌面应用。
- A 验证素材读取、基本播放/定位、标注读取和授权测试写入/回退。
- B 验证直接寻帧与预处理缓存的响应、资源及准确性边界。
- 2026-10-10 整理已有 Git 仓库、项目规则、原型和实验文档；不新增播放器功能。

## 尚未批准的正式开发

正式 UI、快捷键、播放列表、完整标注编辑器、长期缓存管理、多策略框架、安装发布与更新均不属于已完成 PoC 的交付范围。JPEG 只是 B 验证方案，不是已决定的正式缓存格式。

尚未发现官方原生播放位置双向同步依据，不以注入或未支持同步作为当前方案前提。是否开展下一阶段、采用何种正式实现，由用户另定范围。
